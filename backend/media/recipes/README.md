# Tarif fotoğrafları

Her tarif için `<tarif-slug>.jpg` (örn. `hi-bal-hardalli-tavuk.jpg`) buraya konur; API otomatik
olarak `/api/media/recipes/<slug>.jpg` adresinden sunar ve uygulama tarifte gösterir. Dosya yoksa
uygulama yemek simgesini gösterir. Önerilen: JPEG, 4:5 dikey, en az 1200x1500, 500 KB altı.
Kaynak: kendi ürettiğimiz ya da lisanslı görseller (Mealime fotoğrafları kullanılamaz).
